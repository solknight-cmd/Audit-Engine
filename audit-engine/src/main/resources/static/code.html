description

How Verdicts Are Decided

[01] CORE FORMULA
Every balance sheet is checked against:

Assets = Liabilities + Equity

[02] FIGURES MUST BE IN THE DOCUMENT
The AI model reads the totals, and the server only uses a figure if that number is actually printed in the document. Anything else is reported as unverified, and the audit can't pass.

[03] VERDICTS
Passed: the equation balances and the AI found no serious issue. High leverage: liabilities exceed 80% of assets. Anomaly detected: the equation doesn't balance, or the AI flagged a serious issue. Unable to verify: the totals couldn't be read or confirmed.

[04] THE VAULT
Results are append-only: the database refuses to edit or delete them. Each record stores a SHA-256 fingerprint of the exact file audited.
