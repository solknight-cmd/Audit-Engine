Your Data in the Vault

Audit results and extracted text are stored in PostgreSQL. Results are append-only: database triggers reject any edit or deletion. Encryption at rest depends on the hosting environment and will be switched on for every hosted deployment; it is not something the platform guarantees today.

Sign-In and Access

Passwords are stored as BCrypt hashes. Sessions use a cookie other sites can't send or read, and every change needs a CSRF token. Each request is checked against the user's company on the server. Hosted deployments must run over HTTPS, which is set up at deployment.

Where Your Documents Go

To review a statement, Vault Core sends its extracted text, or page images for scans and photos, to an AI provider: currently Groq. Original files are not kept after processing; the vault stores the extracted text, the report and a SHA-256 fingerprint. Security testing today is the platform's own automated test suite (company isolation, the append-only vault, CSRF and sign-in). An independent penetration test is planned before production pilots.
