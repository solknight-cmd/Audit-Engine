Product Architecture

How Vault Core Works.

How a financial statement moves from upload to verdict, and what is checked along the way.

SYSTEM ARCHITECTURE
dataset Module 01

The Ingestion Layer

Upload text PDFs, scanned PDFs, photos, Excel, CSV or plain text. Text is extracted directly; scanned pages and photos go to a vision model; spreadsheet numbers keep their exact formatting. Every file is fingerprinted with SHA-256 the moment it arrives.

FORMATS
PDF · Scans · XLSX · CSV · JPG
FINGERPRINT
SHA-256 per file
analytics Module 02

The Analysis Core

Figure Verification

The AI model reports the headline totals. The server only accepts a figure if it is printed in the document, then checks Assets = Liabilities + Equity and the leverage ratio itself.

AI Review

A language model reviews the statement for inconsistencies, missing line items and unusual entries, and has to point to something specific for every finding.

CHECKS ARITHMETIC + AI
shield_lock Module 03

The Append-Only Vault

Results are written once. The database rejects any attempt to edit or delete them, whichever program tries. Each record keeps the SHA-256 fingerprint of the exact file audited, so anyone holding the original document can confirm it is the one the verdict refers to.
